# Masthon

A simple API for linking mastodon to your python codes.

#Author : org.literie.gator
#LastVersion : 0.1.1 beta


# How it works

The package is organized around a main class : The [[Client]]. It contain your app infos a mainloop and some decorator generators like `@schedule()` ([[Client#`schedule(...)`|Class.schedule()]]).

When you defined all your functions, you can start the #mainloop ([[Client#`run(...)`|Client.run()]]) and see it working (normally :) ... ).
