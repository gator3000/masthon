Masthon

A simple API for linking mastodon to your python codes.

#Author : org.literie.gator

#LastVersion : 0.2 beta

#FormatedDocumentation : at Documentation on Gitlab Pages

Features

  • Masthon engine
    • main loop
    • asynchronous
  • Server Interactions
    • Make a request to your server
    • Statuses
      • Post
      • Delete
      • Upload a file
    • Users
      • Get user
    • Timelines
      • Home & Tags
        • Get timeline
      • Notifications
        • Get unread notification count
        • Get last received notifications
      • Markers
        • Post
        • Get
  • Event managing
    • Handler
      • unread notification
      • new mention
      • new post in timeline
        • home
        • account
        • tag
  • CLI interface
    • Handler
      • some defaults commands
      • create new command
  • Scheduling
    • Handler
      • One time execution
      • Loop back

How it works

The package is organized around a main class : The Client. It contain your app infos a mainloop and some decorator generators like @schedule() (Client.schedule()).

When you defined all your functions, you can start the #mainloop (Client.run()) and see it working (normally :) ... ).
