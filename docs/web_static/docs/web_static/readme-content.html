Masthon

A simple API for linking mastodon to your python codes.

#Author : org.literie.gator

#LastVersion : 0.4 Beta

#FormatedDocumentation : at Documentation on Gitlab Pages

Features

  • Version Check __main__ py > Version Checker
  • Masthon engine
    • main loop -> #mainloop
    • asynchronous (actually, threading) #threading
    • Simple events #simpleevents Client py > execute()
      • on_start
      • on_stop
  • Server Interactions
    • Make a request to your server #RequestAPI
    • Statuses
      • Post Client py > post_status()
      • Delete Client py > delete_status()
      • Upload a file Client py > upload_media()
    • Users
      • Get user
      • Modify attributes (name, bio, profile picture ...)
    • Timelines
      • Home & Tags (& user's tl)
        • Get timeline
      • Notifications #notifications
        • Get unread notification count Client py > unread_notifications_count()
        • Get last received notifications Client py > get_notifications()
      • Markers #markers
        • Post Client py > post_marker()
        • Get Client py > get_marker()
  • Event managing
    • Handler #events Client py > listen_for()
    • Event types DataClasses py > Event
      • unread notification
      • new mention
      • new post in timeline
        • home
        • account
        • tag
  • CLI interface #CLI
    • Handler
      • some defaults commands Client py > commands
      • create new command Client py > add_command()
  • Scheduling #scheduling #loopedfunctions
    • Handler
      • One time execution Client py > schedule()
      • Loop back Client py > looped_every()

and more at Client py.

How it works

The package is organized around a main class : The Client py. It contain your app infos a mainloop and some decorator generators like @schedule() (Client py > scehdule()).

When you defined all your functions, you can start the #mainloop (Client py > run()) and see it working (normally :) ... ).

You can just try the module with __main__ py > Try masthon

Handle the package

At Examples you can find examples which explain how to handle main features. To go deeper you can Contact me or browse Client py, Events py, DataClasses py, utils py, Exceptions py, __init__ py and so on.
